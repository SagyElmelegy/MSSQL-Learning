# MSSQL-Learning

A structured collection of my SQL learning journey — from basic syntax to query optimization.

---

## About This Repository

I started this repository to track my progress as I learned T-SQL from the ground up. What began as simple practice files grew into a comprehensive set of notes and scripts covering most of what I believe a junior data professional should know.

Every file here represents something I wrote, tested, and understood (or struggled with until I did).

---

## What's Inside

| Category | Topics Covered |
|----------|----------------|
| **Fundamentals** | Essential clauses, DDL, DML, data types, NULL handling |
| **Joins** | Inner, outer, cross, and multi-joins |
| **Functions** | String, numeric, date/time, NULL, aggregate |
| **Set Operations** | UNION, INTERSECT, EXCEPT |
| **Subqueries & CTEs** | Correlated subqueries, Common Table Expressions |
| **Window Functions** | Ranking, aggregate, and value functions (ROW_NUMBER, LAG/LEAD, etc.) |
| **Views** | Standard views, indexed views, view design patterns |
| **Indexing** | Clustered vs nonclustered, unique, filtered, columnstore |
| **Performance** | Execution plans, query hints, index maintenance |
| **Advanced** | Stored procedures, triggers, table partitioning |
