# MSSQL-Learning

A structured collection of my SQL learning journey — from basic syntax to query optimization.

---

## About This Repository

I started this repository to track my progress as I learned SQL from the ground up. What began as simple practice files grew into a comprehensive set of notes and scripts covering most of what I believe a junior data professional should know.

Every file here represents something I wrote, tested, and understood (or struggled with until I did).

---

## My Learning Approach

I didn't just read tutorials. For each topic:

1. Wrote the syntax from memory
2. Ran queries against sample databases (AdventureWorks, Northwind) and (SalesDB)
3. Broke things intentionally to understand error messages
4. Added comments explaining *why* something works (not just *what* it does)

The `.docx` files contain deeper dives — my own summaries of concepts that took longer to click.

Two reasons:

**Second** — When I forget something (which happens), I come back here instead of Googling from scratch. It's my personal SQL reference.
