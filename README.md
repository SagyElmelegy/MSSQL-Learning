## My Learning Approach

I didn't just read tutorials. For each topic:

1. Wrote the syntax from memory
2. Ran queries against sample databases (AdventureWorks, Northwind) and (Sales, SalesDB)
3. Broke things intentionally to understand error messages
4. Added comments explaining *why* something works (not just *what* it does)

The `.docx` files contain deeper dives — my own summaries of concepts that took longer to click.

## Why I Built This

Two reasons:

**First** — I wanted proof of my learning. Not just certificates, but actual code I wrote.

**Second** — When I forget something (which happens), I come back here instead of Googling from scratch. It's my personal SQL reference.
